| Termo | Significado |
|---|---|
| **Agente Inbound** | O agente de IA que atende consultas recebidas pelo WhatsApp |
| **Lead** | Uma pessoa que entrou em contato com seu negócio com interesse em uma viagem |
| **Oportunidade** | Um lead qualificado que se tornou uma potencial venda no painel |
| **Qualificação** | O processo pelo qual o agente determina se um lead é uma oportunidade real |
| **Handoff** | O momento em que o agente passa a conversa para o vendedor humano |
| **Mission Control** | O painel onde se vê o status de cada oportunidade e a operação comercial |
| **Kanban** | O formato visual do painel: colunas que representam etapas da venda |
| **Rastreamento** | A conexão do WhatsApp de um vendedor para que Trama veja suas conversas |
| **Toque** | Uma mensagem de acompanhamento pós-cotação (há 3 toques no protocolo) |
| **Conversa** | Cada pessoa nova que contata o agente. Independentemente de quantas mensagens, é 1 conversa. |
| **Número dedicado** | O número de WhatsApp exclusivo para o agente Trama |
| **Número rastreado** | O número de WhatsApp de um vendedor conectado à Trama para acompanhamento |
| **Campanha** | Um agrupamento de oportunidades por contexto comercial (promoção, temporada, destino) |
| **Template** | Um formato de mensagem pré-aprovado pela Meta para enviar notificações pelo WhatsApp |
| **Temperatura** | Quão pronta para comprar uma oportunidade está: quente, morno ou frio |
| **Dormida** | Uma oportunidade que saiu do fluxo ativo por inatividade e pode ser reativada |
| **Fora do funil** | A aba com as oportunidades dormidas e arquivadas, fora do pipeline ativo |
| **Coexistência** | O modo em que Trama observa o WhatsApp de um vendedor sem que ele troque de número nem de app |
| **Catálogo** | A biblioteca de pacotes e serviços que o agente usa para assessorar o viajante |
