## Quando transfere para o vendedor

O agente transfere a conversa para o vendedor designado quando:

- Obteve dados suficientes para qualificar o lead (destino + datas + passageiros como mínimo)
- O viajante pede para falar com uma pessoa
- O viajante faz uma pergunta que o agente não consegue responder
- A conversa requer negociação ou atendimento personalizado

## Personalização

Cada negócio pode personalizar:

- As informações que o agente conhece (destinos, serviços, políticas)
- O tom e estilo da conversa
- As regras de transferência (quando passa para o vendedor)
- Os dados que considera obrigatórios para qualificar
