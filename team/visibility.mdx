## The customer assignee

Each customer has an **assignee**: the member responsible for that relationship.

- It's assigned automatically to the sales rep who takes the lead.
- The Owner and the Admin can reassign it at any time.
- Customers **without an assignee** stay visible to the whole team, so anyone can pick them up.

This assignee is the basis of per-customer visibility: if the Owner limits visibility, each person sees only the customers (and the conversations of those customers) they're assigned to.

## The visibility settings

From the **Permissions and visibility** screen, the Owner turns on two settings (only the Owner can access this screen):

| Setting | When enabled | When disabled |
|---|---|---|
| **Opportunities** | Each sales rep sees only the opportunities assigned to them. | The whole team sees the entire pipeline. |
| **Customers** | Each member or admin sees only the customers they're assigned to. | The whole team sees all customers. |

The Customers setting also covers the conversations in **Agents (Inquiries)**: if visibility is limited, each person sees only the conversations of their assigned customers. Conversations with no assigned customer stay visible to everyone.

## Summary by section

| Section | Owner | Admin | Sales rep |
|---|---|---|---|
| **Mission Control** | Whole business + weekly email | View of their own performance | View of their own performance |
| **Opportunities** | Full pipeline + metrics + filter | Pipeline (per config) + metrics + filter | Pipeline (per config), no metrics |
| **Customers** | All + metrics + reassign | Assigned or all (per config) + metrics + reassign | Their assigned customers, no metrics |
| **Team** | Full access | Full access | No access |
| **Catalog** | Create / edit / delete + metrics | Create / edit / delete + metrics | View only, no metrics |
| **Agents (Inquiries)** | View + Summary/Config + metrics | View + Summary/Config + metrics | View only, no config or metrics |
| **Permissions and visibility** | Exclusive access | No access | No access |
